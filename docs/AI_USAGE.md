# AI Usage and Transparency

## Purpose

AI tools may be used as engineering assistants for learning, brainstorming, planning, documentation, code review, troubleshooting, and discussion of design alternatives.

AI assistance does not replace the project author's responsibility for engineering judgment, implementation, testing, validation, safety, or technical accuracy.

## Permitted Uses

AI tools may assist with:

- Explaining unfamiliar robotics, Linux, ROS 2, C++, Python, electronics, and software concepts
- Brainstorming system architectures and implementation approaches
- Comparing hardware and software alternatives
- Reviewing documentation for clarity and completeness
- Suggesting code structures, test cases, debugging steps, and refactoring opportunities
- Identifying possible risks, assumptions, and missing requirements
- Improving grammar, organization, and presentation
- Supporting Git, GitHub, and development-environment workflows

## Human Responsibilities

The project author remains responsible for selecting the final design, understanding committed code, reviewing AI-assisted content, integrating hardware, conducting tests, verifying claims, evaluating risks, and ensuring confidential information is excluded.

## Verification Standard

AI-generated suggestions are treated as unverified inputs until reviewed and tested. Before AI-assisted code or technical guidance is accepted, the project author should understand the approach, review assumptions, modify it to match project requirements, test it in the intended environment, and record important results and limitations.

## Documentation Practice

Major AI-assisted contributions may be noted when they materially affect a result.

- **AI contribution:** Suggested options, explanations, examples, or review comments.
- **Human decision:** Selected the final approach, implemented it, and verified the result.

## Prohibited Uses

AI tools will not be used to fabricate test results, claim unverified functionality, conceal known failures, introduce unexplained code, publish confidential information, or make final safety decisions without independent review.

## Accountability

All repository content is published under the project author's responsibility, regardless of whether AI tools contributed to its development.
